# Core HMS - Hospital Management System

A comprehensive Django-based Hospital Management System with multi-role access (Owner, Doctor, Patient, Receptionist).

?? **[Live Website Link](https://MediNEXA.pythonanywhere.com)**

## Features
* **Superuser/Owner Dashboard:** Full control over hospital staff and operations.
* **Doctor Module:** Manage appointments, prescriptions, and patient records.
* **Patient Module:** Book appointments and view medical history.
* **Receptionist Module:** Manage walk-in appointments and billing.
* **Automated Email Notifications:** OTPs and alerts sent via email.
* **Dynamic UI:** Built with HTML, CSS, and Bootstrap.
